# H3lio FarmBook

An interactive prototype for an agricultural intelligence ecosystem connecting farmers, cooperatives, researchers, experts, equipment providers, and storage providers.

## Prototype

Static frontend prototype built with HTML, CSS, and JavaScript. Includes dashboard and module navigation, sample data, filters, forms/modals, and demo interactions.

## Local run

Open `index.html` in a browser, or serve this folder using a local static HTTP server.

## Deployment

See `DEPLOY.md`. This prototype can be hosted on Cloudflare Pages as a static site.

## Status

Prototype only. Backend services, authentication, persistent data, production AI integrations, transactions, and external API integrations are not yet implemented.
